# Análisis de Rendimiento y Estrategia Comercial - Alura Store

Análisis integral de una red de 4 unidades de negocio mediante Python. El proyecto audita la salud financiera, la eficiencia logística y la composición de ventas para transformar datos crudos en decisiones estratégicas de inversión y optimización.

## 🎯 Objetivos del Proyecto
* **Consolidación de Datos:** Procesamiento de fuentes heterogéneas de facturación.
* **Auditoría Financiera:** Cálculo de KPI críticos (Ticket promedio, Share de mercado, Variaciones vs. Promedio).
* **Análisis Logístico:** Evaluación de la relación costo de envío vs. categoría de producto.
* **Diagnóstico Estratégico:** Identificación de activos de alto rendimiento y unidades con bajo retorno de inversión.

## 🛠️ Stack Tecnológico
* **Lenguaje:** Python 3.x
* **Librerías:** Pandas (procesamiento), Matplotlib & Seaborn (visualización), Numpy (análisis numérico).

## 📊 Insights Clave
1.  **Tienda 1:** Principal motor financiero de la red con el ticket promedio más alto.
2.  **Tienda 2:** Líder en volumen operativo y eficiencia logística.
3.  **Tienda 3:** Especialización de nicho con alto impacto en costos de envío.
4.  **Tienda 4:** Identificada como activo con síntomas de estancamiento estratégico.

## 🚀 Cómo ejecutar
1. Clonar el repositorio.
2. Asegurarse de tener instaladas las dependencias: `pip install pandas matplotlib seaborn`.
3. Ejecutar el notebook `Challenge_Alura_Store.ipynb`.
